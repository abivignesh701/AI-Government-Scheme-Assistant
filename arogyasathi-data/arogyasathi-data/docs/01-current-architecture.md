# Current Architecture

## Analysis
There is **no current software architecture** deployed or implemented in this repository. 

Currently, the architecture solely consists of a **Data Architecture**:
- **Schemes** map to **Rules**, **Benefits**, and **Documents** via foreign key-like IDs (e.g., `scheme_id`).
- All configurations are stored in flat JSON files.
- The `master/` directory acts as a registry.

## Missing Components
- Frontend Framework
- Backend Framework
- Database
- Eligibility Execution Engine
- RAG Pipeline
- API Layer
