# Development Roadmap

Based on the audit, here is the vertical slice implementation sequence:

- **Module 0** — Repository & data audit
- **Module 1** — Foundation, architecture and shared contracts (Set up Next.js + FastAPI + PostgreSQL)
- **Module 2** — Government scheme knowledge system (Data ingestion & APIs + Scheme UI)
- **Module 3** — Citizen onboarding + profile normalization (Form UI + Profile validation APIs)
- **Module 4** — Deterministic eligibility engine (Engine logic + JSON Test passing + Result APIs)
- **Module 5** — Eligibility journey + explainability UI (Connecting profile collection to eligibility results visually)
- **Module 6** — RAG ingestion + retrieval + citizen Q&A (Vector DB + Chunking + RAG Chat UI)
- **Module 7** — Scheme explorer + source-backed details (Deep dive scheme UI)
- **Module 8** — Documents + application guidance
- **Module 9** — Multilingual experience
- **Module 10** — Voice input + read aloud
- **Module 11** — Elderly / accessibility / caregiver modes
- **Module 12** — Source freshness + admin/data verification
- **Module 13** — Testing, security and observability
- **Module 14** — Production deployment and final QA
